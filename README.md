### Aaron Scheiner: part-time senior software engineer, London

I work with small teams whose products involve **hardware, devices or video**. That covers bringing up and debugging Linux on hardware, reverse engineering protocols so devices can work together, and the TypeScript and cloud systems around them. I work remotely, about four days a week, for clients in the UK and abroad. I contract through my UK limited company, Tandem Delta Consulting Limited.

**What I'm good at**

- **Linux and hardware.** Kernel drivers, firmware, embedded Linux and ESP32/ESPHome, and getting hardware to do things its vendor didn't plan for.
- **Reverse engineering for interoperability.** Serial, BLE and network protocols, firmware images and teardowns.
- **Video and streaming.** Hardware encoders, NDI, live production systems and capture devices.
- **Product engineering.** TypeScript, Node.js and React, Cloudflare Workers, AWS and Docker, with Go, Python and Java where they fit.
- **Running the work.** I've led teams and run my own media production business, so I scope work, communicate clearly and ship.
